# Employee and Project Data Analysis using Python

## Project Overview

This project demonstrates data manipulation and analysis using Python, Pandas, and NumPy. It uses an exercise dataset created within a Jupyter Notebook to explore employee information, project assignments, project costs, and designations.

The notebook covers data creation, handling missing values, transforming columns, joining DataFrames, calculating bonuses, updating designations, grouping records, and filtering data.

## Project Objectives

- Create and work with structured employee and project datasets.
- Handle missing project-cost values.
- Split employee names into separate columns.
- Join employee, seniority, and project data.
- Calculate employee bonuses and update designations.
- Group and filter data to derive useful observations.

## Dataset Structure

The notebook creates the exercise data in code before saving and reading the CSV files. It creates five employee records and 14 project records.

| File | Purpose |
|---|---|
| `Employee.csv` | Employee information |
| `Seniority.csv` | Employee seniority-level information |

These CSV files are generated by running the notebook. Their absence from the GitHub repository does not necessarily indicate missing input files.

## Notebook Exercises

### 1. Create DataFrames
Create employee, seniority, and project data using Pandas.

### 2. Handle Missing Project Costs
Fill missing cost values using the running-average rule implemented in the notebook. This demonstrates missing-value treatment in a dataset.

### 3. Split Employee Names
Separate employee names into individual columns to make the data easier to analyze.

### 4. Join DataFrames
Combine employee, seniority, and project information using the relevant employee identifiers.

### 5. Calculate Bonuses
Apply the bonus calculation defined in the exercise to employee records.

### 6. Update Designations
Update employee designations according to the designation-level convention used in the notebook. Refer to the notebook's mapping or conditions for the exact rules.

### 7. Group and Filter Data
Group records and filter the results to answer questions about employee project costs and assignments.
